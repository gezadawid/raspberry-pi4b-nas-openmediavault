# raspberry-pi4b-nas-openmediavault
Własny serwer NAS oparty o Raspberry Pi 4B, Debian Linux i OpenMediaVault.

## Zakres projekt
- budowa serwera NAS na Raspberry Pi 4B,
- instalacja systemu Linux,
- konfiguracja OpenMediaVault,
- konfiguracja SSH,
- konfiguracja usług SMB/CIFS,
- tworzenie użytkowników i uprawnień,
- podłączenie i konfiguracja dysku SSD,
- mapowanie dysku sieciowego w systemie Windows.

## Wykorzystane technologie
- Raspberry Pi 4B
- Debian Linux / Raspberry Pi OS
- OpenMediaVault
- SSH
- SMB/CIFS
- Ethernet
- Dysk SSD

## Cel projektu
Celem projektu było stworzenie działającego domowego serwera NAS do przechowywania i udostępniania plików w sieci lokalnej.
